# Working conventions (set by the project owner)

- Commit and push every change to `master`, the repository's main branch.
  Do not leave work on side branches.
- Show every change in both forms: the desktop web app and the phone app
  (PWA). Capture before/after screens at desktop (1440 x 900) and phone
  (390 x 844) sizes and present them side by side. In the running app,
  `/simulator` shows both live.
- Documents and formal text (agreements, letters, reports): Times New Roman,
  11 or 12 pt, justified. No em-dashes, no double spaces.
- No AI or tool watermarks anywhere: no "Generated with", no
  "Co-Authored-By" or session trailers in commits, PR bodies, documents or
  UI text.
